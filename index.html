Acropolis Campus Hiring - API Specification

Objective

Build and host a REST API (POST method) at endpoint /bfhl that processes an array containing numbers, alphabets, and special characters, returning categorized outputs, arithmetic sum, and a reversed alternating-caps character concatenation string.

Response Keys

  • is_success (boolean)
  • user_id: {full_name_ddmmyyyy} (e.g. karan_patel_26052026)
  • email: karan.patel@acropolis.in
  • roll_number: ACR-2026-XYZ
  • even_numbers (array of even integer strings)
  • odd_numbers (array of odd integer strings)
  • alphabets (array of letters in UPPERCASE)
  • special_characters / sepcial_characters (array of non-alphanumeric chars)
  • sum (sum of all integer strings)
  • concat_string (alphabetic characters, reversed, alternating caps e.g. "ByA")
